# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en este proyecto, evita abrir un issue público con detalles explotables. Repórtala de forma privada al propietario del repositorio desde la pestaña **Security** de GitHub o mediante un aviso privado.

Incluye una descripción clara, los pasos para reproducir el problema, el impacto potencial y cualquier mitigación conocida.

## Buenas prácticas

No incluyas claves API, tokens, contraseñas ni datos personales en commits, issues o solicitudes de cambios. Las credenciales detectadas deben revocarse y reemplazarse inmediatamente.
