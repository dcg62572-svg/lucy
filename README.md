# Lucy

Página estática para **LUCY · Guía 9 pasos**, con el contenido textual del PDF, el fondo visual proporcionado y un botón de descarga del documento original.

## Uso local

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8080
```

Después visita `http://localhost:8080`.

## Archivos

- `index.html`: página completa y texto de la guía.
- `styles.css`: diseño responsive con fondo neón, navegación y modo impresión.
- `assets/lucy-background.jpg`: fondo proporcionado.
- `assets/LUCY-guia-9-pasos.pdf`: PDF descargable.
